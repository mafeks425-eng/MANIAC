# Maniac Hunt — Forge 1.20.1

Мультиплеерный хоррор-мод для Minecraft Java 1.20.1 / Forge 47 / Java 17.

## Сборка
GitHub Actions автоматически собирает мод при каждом push в `main`.
Открой вкладку **Actions**, выбери последний запуск **Build Maniac Hunt** и скачай артефакт **ManiacHunt-Forge-1.20.1**.

Локально: `gradle build`. Готовый JAR появится в `build/libs/`.

## Сейчас реализовано в базовой версии
- Предметы: бита, лом, ножницы, гаечный ключ, топливо, ключ-карта.
- Блоки: генератор, капкан, растяжка, верёвочная ловушка.
- Ловушки обездвиживают выжившего на ограниченное время.
- Другой выживший может подойти к ловушке и нажать ПКМ пустой рукой, чтобы освободить пленника.
- Роль маньяка назначается командой оператора: `/maniac start <ник>`.
- Сброс раунда: `/maniac stop`.

Это ранний игровой прототип: полноценные анимации, уникальные 3D-модели, меню раунда, настоящий процесс ремонта генератора и система выходов ещё требуют дальнейшей разработки.
